# L'Art du Deal

Site vitrine sur la négociation et l'art de conclure des accords.

## Contenu

- **11 éléments du deal** (penser grand, protéger le risque, levier, etc.)
- Méthode **DEAL** en 4 étapes
- Tactiques de terrain
- Contact **WhatsApp**

## Local

```bash
npm start
```

→ http://localhost:3040

## Déploiement Vercel

Repo connecté à Vercel — déploiement automatique sur `main`.

## Config

Numéro WhatsApp : `public/js/app.js` → `WHATSAPP_NUMBER`
